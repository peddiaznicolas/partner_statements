# Customer Statement Dashboard OWL - Advanced Edition

## Complete migration to OWL framework

This module represents the complete migration of customer_statement features to pure OWL framework.

## Key Features
- Customizable aging brackets
- Interactive OWL dashboard  
- Chart.js visualizations
- Portal access
- PDF/Excel export
- Email automation
- Professional UI/UX

## Installation
1. Copy module to addons directory
2. Restart Odoo server
3. Install "Customer Statement Dashboard OWL - Advanced"
4. Access via: Statement Dashboard OWL > Advanced Dashboard

## Competitive Advantages
- Modern OWL framework vs legacy HTML
